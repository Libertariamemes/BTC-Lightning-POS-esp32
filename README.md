# ⚡ Bitcoin Lightning POS (ESP32)

### Fast, Low-Cost, and Decentralized Bitcoin Payments

This project is an open-source Bitcoin Point of Sale (POS) machine powered by an **ESP32 microcontroller**. It leverages the Lightning Network for instant, low-fee transactions, enabling merchants to accept Bitcoin seamlessly without traditional financial intermediaries.

---

## 🚀 Features

* ✅ **Lightning Fast** – Instant payment confirmation via the Lightning Network.
* ✅ **Low-Cost & Scalable** – Near-zero fees, ideal for small businesses and micro-transactions.
* ✅ **User Interface** – Smooth, responsive UI powered by **LVGL**, with screens designed and code-generated by **EEZ Studio by Envox**.
* ✅ **Capacitive Touch** – Native support for the **GT911** touch controller.
* ✅ **WiFi Manager** – Integrated captive portal for easy network configuration without hardcoding credentials.
* ✅ **Flexible Backend** – Currently utilizes **Alby via LNbits**, but can be easily switched to a private **LND** node.
* ✅ **Serial Remote Control** – Debug and trigger invoices/touches via a serial terminal.

---

## 🛠 How It Works

1.  **Input**: The merchant enters the transaction amount on the ESP32 device.
2.  **Generation**: The device communicates with the LNbits/VPS bridge to generate a Bolt11 Lightning invoice.
3.  **Display**: The invoice is rendered as a QR code on the TFT screen.
4.  **Payment**: The customer scans the QR code with any Lightning wallet.
5.  **Verification**: The device polls the backend every 5 seconds. Once the payment is verified, the screen turns **Green** with a "PAID OK" confirmation.

---

## 💻 Software Stack

* **Firmware**: C++/Arduino Framework for ESP32.
* **UI/Graphics**: LVGL (Light and Versatile Graphics Library).
* **Design Tool**: EEZ Studio for LVGL screen generation.
* **Backend**: Alby / LNbits API via REST.
* **Communication**: Secure HTTPS requests using `WiFiClientSecure` and `HTTPClient`.

---

## 📋 Hardware Requirements

* **ESP32-CYD**: (Cheap Yellow Display / ESP32-2432S028R).
* **Touch**: TFT Display with GT911 Capacitive Touchscreen.
* **Power**: 5V USB-C or Battery.

## 🔧 Setup Instructions

### 1. Compilation
* Copy the contents of the `library` folder included in this repo to your `Arduino/libraries` folder.
* Open the `.ino` file in Arduino IDE.
* Ensure your board is set to **ESP32 Dev Module** and the partition scheme is set to **Huge App**.

### 2. Flashing
If you are starting from scratch, follow this step-by-step video guide on how to flash and compile:
👉 **How to Flash from Zero:** https://youtu.be/K44nnlhABAQ

### 3. WiFi & Backend Configuration
* Upon first boot, the POS will start its own Access Point (AP) named `AutoConnectAP`.
* Connect your smartphone to this network.
* A captive portal will appear. Enter your WiFi credentials.
* Configure your LNbits credentials (API Key and URL) via the same interface.
* **Backend Guide:** https://youtu.be/vgjEAOR883I?si=2dsIBsVzTYJbWO1C *(Note: Video covers most logic; update for latest commit coming soon).*

## ⌨️ Debugging & Serial Commands

Use the Serial Monitor (**115200 baud**) for maintenance and remote control:

* `I:amount` – (e.g., `I:500`) Remotely trigger an invoice for 500 sats.
* `P:` – Force an immediate manual payment check.
* `T:x,y` – Emulate a screen touch at coordinates X, Y.
* `C` – **Cancel** current payment checking and return to the main menu.
